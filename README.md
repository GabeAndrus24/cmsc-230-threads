# CMSC 230: threads, in class

The project for the class pages on threads. It holds Monday's `Numbers` and
`NumberCounter` with their tests, and `Account` and `Transfers` for
Wednesday's section 3; `test/TransfersTest.java` is empty, for your own test.

Make a copy of your own first: click **Use this template**, then **Create a
new repository**, under your own account and **Private**. Open your copy in
IntelliJ with File, New, Project from Version Control, and its address.
IntelliJ reads `pom.xml` and fetches JUnit by itself. Run a program from the
arrow beside its `main`, and a test from the arrow beside its name. Commit
and push before you leave, so the work follows you to the next computer.
